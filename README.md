# Simple JavaScript Project

This project is a basic web page built with **HTML** and **JavaScript**.
It is intended as a small exercise to practice fundamental concepts of web development and JavaScript programming.

## Project Structure

- `index.html` – The main web page of the project. It defines the structure and basic content of the site.
- `script.js` – The JavaScript file that adds behavior and interactivity to the page.
- `README.md` – Project description and basic documentation.

## Description

The project demonstrates:

- How to link a JavaScript file to an HTML page.
- How to manipulate the DOM (Document Object Model).
- How to respond to user actions (for example, button clicks or form inputs).
- How to organize simple JavaScript logic in a separate file.

It is mainly for **learning purposes**, helping to understand the interaction between HTML and JavaScript in a clear and minimal example.

## Goals

- Practice basic JavaScript syntax.
- Understand how scripts are loaded and executed in the browser.
- Experiment with simple interactions and dynamic changes on the page.

## Future Improvements (Optional Ideas)

- Add more interactive elements (forms, buttons, messages).
- Improve the visual style with CSS.
- Organize the JavaScript code into reusable functions or modules.
